# 1. What is Programming?

**Programming** is the process of giving instructions to a computer to perform a specific task.

A computer cannot think or make decisions on its own. It follows the instructions that we provide.

We give these instructions using a **programming language**, such as:

- Python
- C#
- Java
- JavaScript

---

## 🌍 A Simple Real-Life Example

Imagine you want to make a cup of tea.

You would give instructions like:

1. Boil water.
2. Add tea powder.
3. Add milk.
4. Add sugar.
5. Boil for a few minutes.
6. Pour the tea into a cup.

These are **step-by-step instructions**.

Similarly, when we want a computer to perform a task, we give it step-by-step instructions using a programming language.

### Simple Comparison

```text
Real Life:

Instructions
     ↓
Person performs the task


Programming:

Instructions
     ↓
Computer performs the task
```

---

# 🐍 Example in Python

Suppose we want the computer to display:

**Hello World**

We can use:

```python

```

### What does this mean?

- `print()` → Tells Python to display something.
- `"Hello World"` → The message that we want to display.

```text

```

# 🧑‍💻 Simple Example

Imagine a company has **10,000 employees** and needs to calculate everyone's salary.

## ❌ Without Programming

Someone may have to calculate each employee's salary manually.

For example:

```text
Employee 1 → Calculate salary
Employee 2 → Calculate salary
Employee 3 → Calculate salary
...
Employee 10,000 → Calculate salary
```

This would take a lot of time and effort. 😓

---

## ✅ With Programming

We can write a program that calculates salaries automatically.

For example:

```python
salary = 50000
bonus = 5000

total_salary = salary + bonus

print(total_salary)
```

### Output

```text
55000
```

The computer can perform the same calculation for thousands of employees very quickly.
